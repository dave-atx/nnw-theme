# nnw-theme

Tools for building [NetNewsWire](https://netnewswire.com) themes: preview a theme in a
live gallery, check it in WebKit across Mac, iPhone, and iPad in light and dark, and
package it for release.

Not affiliated with or endorsed by Ranchero Software or the NetNewsWire project.

Work in progress: this is the Node port of the tooling in
[netnewswire-theme-template](https://github.com/dave-atx/netnewswire-theme-template).
